SINENHLANHLA MOIMANE

Website for UTP VIDA MEDIA

UTP VIDA MEDIA is a creative media company specialising in photography, videography, cinematography, and professional modelling services. The primary goal of the website is to make access to professional photography, cinematography, and videography less stressful by providing a platform that showcases the company’s portfolio and attracts new clients. The website will showcase a portfolio of UTP’s best work and help build a network of creatives and clients. The website will create a hub for UTP’s services and offerings in order to attract potential clients and collaborators. It will also promote modelling services and talent portfolios. Ultimately, this website will build brand credibility and visibility.

The website includes:
Homepage
About Page
Services Page
Gallery Page
Contact Page
Terms and Conditions Page
